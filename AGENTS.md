# Project Instructions

## Codebase understanding

- Use the `codebase-memory` MCP tools when repository structure,
  relationships, dependencies, architecture, or impact analysis
  are relevant to the task.
- Prefer codebase-memory queries for structural questions before
  reading many files individually.
- Do not modify files when the user asks for analysis or planning only.
- Before making broad architectural changes, inspect the relevant
  codebase relationships first.
